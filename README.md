# 生态城种质材料试验与权益边界

治理生态城种质材料、合成生物试验、场地、安全和成果权益。

## 参与方与事实

主要参与方包括园区科研运营人员、科研机构、种业与生物制造企业、生物安全审核人员、试验场地管理员。领域资料记录以下已经确认的事实：

- 中新天津生态城合作升级聚焦合成生物制造和现代种业
- 合作区建设生物制造谷和生命科学产业集群
- 双方推动医疗设备和种业等成果转化

## 业务约束

- 材料来源与许可
- 衍生谱系
- 试验审批
- 场地与保存条件
- 成果权益追溯

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/news_context_004.py` 负责读取和校验这些资料。

## 治理后端

`src/governance/` 是种质与试验治理后端（纯标准库，SQLite 持久化）：

- 材料接收登记来源、保存条件、质量批次与许可条款，拆分、混合、繁育、转移、失活沿同一谱系入账
- 取用申请按用途、机构、人员资质、生物安全等级、许可有效期与场地容量评估可执行范围；高风险例外须提交人以外的生物安全审核人员复核
- 未授权机构在检索与取用中无法推断受限资源存在
- 污染、丢失、许可撤销、场地故障只冻结受影响材料与试验，已完成环节保留当时依据并生成处置责任
- 扫描与交接回执幂等入账，数量、身份与内容可核对；告警、待复核与试验随访持久化，进程重启不丢
- 管理人员可从任何成果追溯到原始材料、每次转移与适用的合作权益

机制与需求的对应关系见 `docs/governance-design.md`。


```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
